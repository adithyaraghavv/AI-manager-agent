# Database / Folder Structure

## Template folder

A master folder consists of all templates.

## Clients folder

Each client has its own sub-folder, mirroring the 7-phase structure defined in `sdlc_phase_config.json`:

- Client 1
  - 1. Pre-requisites
  - 2. Requirement Analysis
  - 3. System Design
  - 4. Implementation (Coding)
  - 5. Testing (STLC integrated)
  - 6. Deployment
  - 7. Maintenance
- Client 2
- Client 3
